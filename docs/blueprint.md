# **App Name**: I Wear Organic

## Core Features:

- AI-Powered News Aggregation: Fetch news articles from various sources using web scraping and APIs.
- Intelligent Summarization: Automatically summarize news articles using natural language processing for quick consumption. The LLM should act as a tool, selectively extracting key information.
- Customized News Feed: Allow users to customize their news feed based on topics, sources, and keywords.
- Dynamic UI: Create a modern and responsive user interface that adapts to different screen sizes and devices.
- News Categorization: Automatically categorize news articles into different categories such as politics, sports, technology, etc.
- Source Filtering: Allow users to filter news based on the source to customize their consumption.
- Search Functionality: Implement a robust search feature allowing users to find news on specific topics.

## Style Guidelines:

- Primary color: Off-white (#F8F8FF) to mimic newspaper print.
- Background color: Light gray (#E0E0E0) for a subtle contrast.
- Accent color: Dark charcoal (#36454F) for headings and important links.
- Body and headline font: 'Georgia' serif font for readability and a classic newspaper feel, with 'Arial' as a sans-serif fallback.
- Use simple, dark gray icons to represent news categories and actions.
- Implement a dynamic grid layout for displaying news articles, ensuring responsiveness on different devices, with a clear hierarchy.
- Subtle animations for loading new articles and transitioning between different sections, avoiding excessive movement.
